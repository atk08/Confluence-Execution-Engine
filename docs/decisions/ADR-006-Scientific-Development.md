# ADR-006: Scientific Development Process

Status: Accepted

Date: July 2026

## Decision

Confluence Scanner AI will be developed using a scientific, evidence-based process.

Every scoring formula, weighting adjustment, and algorithmic enhancement must be framed as a hypothesis, tested against historical data, and validated before being promoted to production.

## Rationale

The objective is not to build a system that appears intelligent.

The objective is to build a system whose decisions can be measured, reproduced, and continuously improved.

## Consequences

- New formulas begin as experimental.
- Historical testing is mandatory before adoption.
- Engine revisions require documented performance improvements.
- Research results become part of the product's intellectual property.
